# Jayanth Portfolio

A multi-page Next.js portfolio for Jayanth Pallapu with a premium blue-light futuristic theme, animated background motion, and resume-driven content.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
npm run start
```

## Deploy to Vercel

1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Keep the default Next.js settings.
4. Deploy.

## Content notes

- Resume PDF is bundled at `public/assets/Jayanth-Resume.pdf`.
- Profile image is bundled at `public/assets/profile.png`.
- Contact, experience, and project copy currently comes from the provided resume PDF.
- The LinkedIn URL was not preserved in the extracted PDF text, so it should be added once you confirm the exact public profile URL.
